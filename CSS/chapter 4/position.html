Position

Position property is used to specify the type of positioning method for an element. The position property specifies the type of positioning method used for an element (static, relative, absolute, fixed, or sticky).

Types of Positioning

  1. Static
  2. Relative
  3. Absolute
  4. Fixed

Static

Static positioning is the default behavior of an element. Elements with static positioning are not affected by the top, bottom, left, and right properties.

Relative

Relative positioning allows you to position an element relative to its normal position. You can use the top, bottom, left, and right properties to move the element from its normal position.

Absolute

Absolute positioning allows you to position an element relative to its nearest positioned ancestor (an ancestor with a position other than static). If there is no such ancestor, it will be positioned relative to the initial containing block (usually the viewport).

Fixed

Fixed positioning allows you to position an element relative to the viewport, which means it will stay in the same position even when the page is scrolled. You can use the top, bottom, left, and right properties to specify the position of the element.
