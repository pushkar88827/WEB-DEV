Infinite Loops in JavaScript

An infinite loop repeats forever because its stopping condition never becomes false. Since JavaScript runs this loop on the page’s main thread, the browser cannot respond to clicks or repaint the page while it is running.

Example

while (true) {
  console.log("This keeps repeating");
}

This loop never ends: true is always true, so the browser stays busy running the loop.

A loop that stops

let count = 0;

while (count < 5) {
  console.log(count);
  count++;
}

Here, count increases each time. Once it reaches 5, the condition count < 5 becomes false, and the loop ends.

Safety tip: Don’t run a literal infinite loop in a browser page you care about. It can make the tab unresponsive. If it happens, close the tab or stop the script in the developer tools.
