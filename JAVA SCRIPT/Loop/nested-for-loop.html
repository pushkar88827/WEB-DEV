Nested for loop kya hota hai?

Jab ek for loop ke andar doosra for loop likha ho, use nested for loop kehte hain. Bahari loop har baar chalta hai, aur uski har ek baar ki run ke andar andar wala loop poora chalta hai.

Yaad rakho: Outer loop = rows (panktiyan), inner loop = har row ke items/columns.

Example: 3 rows aur 4 columns

for (let row = 1; row <= 3; row++) {
  for (let col = 1; col <= 4; col++) {
    console.log(`row ${row}, column ${col}`);
  }
}

Is example mein outer loop 3 baar chalta hai. Har baar inner loop 4 baar chalta hai. Isliye total 3 × 4 = 12 baar andar ka code chalega.

Chalakar dekho

Button dabane par JavaScript isi logic se 3 × 4 ka grid dikhayegi.

Yahan result dikhega.

Loop ka flow

  1. row = 1: inner loop col = 1 se 4 tak chalega.
  2. row = 2: inner loop phir se 1 se 4 tak chalega.
  3. row = 3: inner loop phir se poora chalega.
  4. Phir outer loop ruk jaata hai, kyunki row ab 3 se bada ho jaata hai.

Use cases: grids, tables, multiplication tables, aur 2D arrays ke items par kaam karna.
