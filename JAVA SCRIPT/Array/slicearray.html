JavaScript Array slice()

Complete Notes | Beginner Friendly | Hinglish

1. What is slice()?

JavaScript mein slice() method ka use array ke kisi specific part ko copy karke ek new array banane ke liye hota hai.

Important: slice() original array ko change nahi karta.

2. Syntax

array.slice(start, end);
  • start: Jis index se elements lena shuru karna hai.
  • end: Jis index se pehle elements lene band karne hain.
  • Dono parameters optional hain.
Golden Rule: Start index include hota hai, lekin end index exclude hota hai.

3. Basic Example

let numbers = [10, 20, 30, 40, 50];

let result = numbers.slice(1, 4);

console.log(result);
Output: 
[20, 30, 40]

Dry Run

Index Value Included?
0 10 No - start se pehle
1 20 Yes
2 30 Yes
3 40 Yes
4 50 No - end excluded

4. Only Start Index

let fruits = ["Apple", "Mango", "Banana", "Orange"];

console.log(fruits.slice(2));
Output: 
["Banana", "Orange"]

Jab end index nahi dete, tab start index se lekar array ke last element tak sab copy ho jaate hain.

5. slice() Without Arguments

let arr = [1, 2, 3, 4];

let copy = arr.slice();

console.log(copy);
Output: 
[1, 2, 3, 4]

Bina arguments ke slice() poore array ki shallow copy banata hai.

6. Negative Index

let numbers = [10, 20, 30, 40, 50];

console.log(numbers.slice(-2));
Output: 
[40, 50]
Negative Index Value
-1 50
-2 40
-3 30

Negative indexes array ke end se count hote hain.

7. Original Array Remains Unchanged

let numbers = [10, 20, 30, 40, 50];

let result = numbers.slice(1, 3);

console.log(result);
console.log(numbers);
Output: 
[20, 30]
[10, 20, 30, 40, 50]
slice() ek naya array return karta hai. Original array ke elements remove nahi hote.

8. slice() vs splice()

Feature slice() splice()
Purpose Part copy karna Add/remove/replace karna
Original array Unchanged Usually changed
Return value Selected elements Removed elements 
let arr = [10, 20, 30, 40];

console.log(arr.slice(1, 3));
// [20, 30]

console.log(arr.splice(1, 2));
// [20, 30]

console.log(arr);
// [10, 40]

10. Practice Questions

  1. [5, 10, 15, 20, 25] mein se index 1 se 3 tak elements nikalo.
  2. Array ke last 3 elements slice() se kaise nikaloge?
  3. Original array change kiye bina uski copy banao.
  4. [10, 20, 30, 40, 50] par slice(-3, -1) ka output predict karo.
  5. slice() aur splice() ke beech do differences likho.

Quick Revision

  • slice() array ka selected part copy karta hai.
  • Start index included hota hai.
  • End index excluded hota hai.
  • Negative indexes end se count hote hain.
  • Original array unchanged rehta hai.
  • slice() ek shallow copy banata hai.
