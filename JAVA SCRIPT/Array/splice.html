JavaScript Array splice()

Complete Notes | Beginner Friendly | Hinglish

1. What is splice()?

JavaScript mein splice() method ka use array mein elements ko remove, add ya replace karne ke liye hota hai.

Important: splice() original array ko modify karta hai.

Iska matlab hai ki splice() use karne ke baad original array ke elements change ho sakte hain.

2. Syntax

array.splice(start, deleteCount, item1, item2, ...);
  • start: Jis index se changes shuru honge.
  • deleteCount: Kitne elements remove karne hain.
  • item1, item2: Optional naye elements jo add karne hain.
splice() removed elements ka ek array return karta hai. Agar koi element remove nahi hua, toh empty array return hota hai.

3. Remove Elements

let numbers = [10, 20, 30, 40, 50];

let removed = numbers.splice(1, 2);

console.log(removed);
console.log(numbers);
Output: 
[20, 30]
[10, 40, 50]

Dry Run

Index Value Action
0 10 Unchanged
1 20 Removed
2 30 Removed
3 40 Shifts to index 1
4 50 Shifts to index 2

splice(1, 2) ka matlab index 1 se start karke 2 elements remove karna.

4. Add Elements

Agar deleteCount 0 hai, toh elements remove nahi honge. Naye elements specified index par add honge. 

let fruits = ["Apple", "Banana", "Orange"];

fruits.splice(1, 0, "Mango");

console.log(fruits);
Output: 
["Apple", "Mango", "Banana", "Orange"]

Index 1 par Mango add hua. Baaki elements aage shift ho gaye.

5. Replace Elements

let colors = ["Red", "Blue", "Green"];

colors.splice(1, 1, "Yellow");

console.log(colors);
Output: 
["Red", "Yellow", "Green"]

Index 1 se ek element remove hua aur uski jagah Yellow add hua.

6. Remove All Elements From an Index

let numbers = [10, 20, 30, 40, 50];

let removed = numbers.splice(2);

console.log(removed);
console.log(numbers);
Output: 
[30, 40, 50]
[10, 20]

Jab deleteCount nahi dete, toh start index se lekar array ke end tak saare elements remove ho jaate hain.

7. Negative Index

let numbers = [10, 20, 30, 40, 50];

numbers.splice(-2, 1);

console.log(numbers);
Output: 
[10, 20, 30, 50]

Negative start index array ke end se count hota hai. Yahan -2 ka matlab index 3, yaani value 40.

8. slice() vs splice()

Feature slice() splice()
Purpose Array ka part copy karna Add, remove, replace karna
Original array Unchanged Modified
Arguments start, end start, deleteCount, items
Return value Selected elements ka new array Removed elements ka array
Memory Trick:
slice = Copy a part
splice = Change the original

9. Try It Yourself

Buttons click karke dekho ki splice() array ko kaise change karta hai. 

let numbers = [10, 20, 30, 40, 50];

// Remove 2 elements starting at index 1
let removed = numbers.splice(1, 2);

10. Practice Questions

  1. [5, 10, 15, 20, 25] mein se index 2 par 2 elements remove karo.
  2. ["HTML", "CSS", "Python"] mein index 1 par "JavaScript" add karo bina kisi element ko remove kiye.
  3. [10, 20, 30] mein 20 ko 99 se replace karo.
  4. [1, 2, 3, 4, 5] par splice(2) ka output predict karo.
  5. splice() ka return value kya hota hai jab koi element remove nahi hota?

Quick Revision

  • splice() original array ko modify karta hai.
  • Elements remove, add aur replace kar sakte ho.
  • deleteCount removed elements ki sankhya batata hai.
  • Removed elements ek new array mein return hote hain.
  • Negative start index end se count hota hai.
