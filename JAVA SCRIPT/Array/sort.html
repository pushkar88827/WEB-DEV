JavaScript Array sort()

Complete Notes | Hinglish | Examples & Practice

1. What is sort()?

JavaScript ka sort() method array ke elements ko ek particular order mein arrange karta hai.

By default, elements ko strings ke roop mein compare kiya jata hai.

Important: sort() original array ko modify karta hai.

2. Syntax

array.sort();
array.sort(compareFunction);

compareFunction optional hota hai. Numbers ko correctly ascending ya descending order mein sort karne ke liye iska use karte hain.

3. Sorting Strings

let fruits = ["Mango", "Apple", "Banana"];

fruits.sort();

console.log(fruits);
Output: 
["Apple", "Banana", "Mango"]

Strings default mein UTF-16 code units ke basis par sort hote hain.

4. Sorting Numbers: Ascending Order

let numbers = [40, 5, 100, 25, 10];

numbers.sort((a, b) => a - b);

console.log(numbers);
Output: 
[5, 10, 25, 40, 100]

Dry Run

Compare function (a, b) => a - b use hota hai.

  • Result negative ho, toh a ko b se pehle rakha jata hai.
  • Result positive ho, toh b ko a se pehle rakha jata hai.
  • Result zero ho, toh dono equal order mein rehte hain.
Remember: Sirf numbers par sort() call karne se numeric ascending order guarantee nahi hota.

5. Sorting Numbers: Descending Order

let numbers = [40, 5, 100, 25, 10];

numbers.sort((a, b) => b - a);

console.log(numbers);
Output: 
[100, 40, 25, 10, 5]

Descending order ke liye b - a use karte hain.

6. Why Default Number Sorting Can Be Wrong

let numbers = [5, 100, 25, 10];

numbers.sort();

console.log(numbers);
Output: 
[10, 100, 25, 5]

Default sort numbers ko strings ki tarah compare karta hai. Isliye numeric sorting ke liye compare function use karo.

7. Sorting Without Changing Original Array

let numbers = [30, 10, 20];

let sorted = [...numbers].sort((a, b) => a - b);

console.log(sorted);
console.log(numbers);
Output: 
[10, 20, 30]
[30, 10, 20]

Spread operator [...numbers] se shallow copy banti hai. Sorting copy par hoti hai, original array unchanged rehta hai.

8. Sort Objects by Property

let students = [
    { name: "Aman", marks: 75 },
    { name: "Riya", marks: 92 },
    { name: "Raj", marks: 60 }
];

students.sort((a, b) => a.marks - b.marks);

console.log(students);
Output: Marks in ascending order 
[
  { name: "Raj", marks: 60 },
  { name: "Aman", marks: 75 },
  { name: "Riya", marks: 92 }
]

10. sort() vs toSorted()

Feature sort() toSorted()
Original array Modify karta hai Unchanged rakhta hai
Return value Sorted original array New sorted array 
let arr = [3, 1, 2];

let result = arr.toSorted((a, b) => a - b);

console.log(result); // [1, 2, 3]
console.log(arr);    // [3, 1, 2]

toSorted() modern JavaScript method hai. Agar environment support nahi karta, toh [...arr].sort(...) use kar sakte ho.

11. Practice Questions

  1. [9, 2, 15, 1, 7] ko ascending order mein sort karo.
  2. [12, 5, 30, 8] ko descending order mein sort karo.
  3. ["Zebra", "Apple", "Mango"] ko alphabetically sort karo.
  4. Original array ko change kiye bina sorted copy banao.
  5. Students ko marks ke basis par descending order mein sort karo.

Quick Revision

  • sort() original array modify karta hai.
  • Default sorting string-based hoti hai.
  • Ascending numbers: (a, b) => a - b
  • Descending numbers: (a, b) => b - a
  • Copy sort karne ke liye: [...arr].sort(...)
  • Non-mutating alternative: toSorted()
