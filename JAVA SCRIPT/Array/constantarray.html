JavaScript Constant Array

1. Declaring a Const Array

const fruits = ["Apple", "Mango", "Banana"];

console.log(fruits);

2. Changing Array Elements

const numbers = [10, 20, 30];

numbers[0] = 100;
numbers.push(40);

console.log(numbers);
// [100, 20, 30, 40]

3. Reassigning a Const Array

const colors = ["Red", "Blue"];

// This causes a TypeError:
// colors = ["Green", "Yellow"];

4. Const Array References

const a = [1, 2, 3];
const b = a;

b.push(4);

console.log(a); // [1, 2, 3, 4]
console.log(b); // [1, 2, 3, 4]

5. Freezing an Array

const days = Object.freeze(["Monday", "Tuesday"]);

// Changes to the array are prevented.
console.log(days);
